# Icons

The app's icon system is **Lucide** (`lucide-react` 0.563.0, ISC license), rendered inline as React components. These 57 files are the exact Lucide SVGs the app imports, saved from `lucide-static@0.563.0`, so a consumer gets the same strokes the product shows.

- Grid 24 × 24, `fill="none"`, `stroke="currentColor"`, `stroke-width="2"`, round caps and joins. Every file is a single-ink mark that takes its color from CSS `color`; shown through `<img>` it renders black, so copy the markup inline (or use the Lucide package) when the icon must take `gray-400`, `white` or `yu-navy`.
- Sizes in the app: `icon-md` 16px (`h-4 w-4`) in buttons, rows and the Toast close; `icon-lg` 20px in nav and card headers; `icon-xl` 24px for feature glyphs and the lightbox close; `icon-sm` 14px and `icon-xs` 12px in dense planner chips; `icon-2xl` 32px in stat tiles and error wells.
- Ink by role: resting icon buttons `gray-400`, hover `gray-600` (or `red-500` / `amber-500` for destructive and reset actions), nav `gray-500` → `yu-navy` when active, on dark surfaces `white` / `white-a80`.

Most-used names (files importing them): `x` (close, 11), `arrow-left` (back links, 11), `trash-2` (delete, 9), `pencil` (edit, 6), `loader-2` (spinners with `animate-spin`, 6), `search`, `plus`, `megaphone`, `book-open` (5 each), `help-circle`, `graduation-cap`, `check-circle` (4), then `user`, `shield`, `mail`, `info`, `clock`, `chevron-right`, `chevron-down`, `check`, `calendar-days`, `calendar`, `bar-chart-3`, `arrow-right` (3), `send`, `message-square-text`, `message-square`, `layout-grid`, `file-text`, `eye`, `chevron-up`, `check-circle-2`, `alert-triangle`, `alert-circle` (2), and once each `zoom-in`, `users`, `user-cog`, `star`, `sparkles` (hero badge), `school`, `rocket`, `reply`, `mouse-pointer-click`, `menu` (mobile nav), `log-out`, `log-in`, `list`, `eye-off`, `external-link`, `download`, `copy`, `chrome` (Google sign-in hint), `chevron-left`, `check-check`, `building-2`, `bell` (notifications), `award`.

Not in this folder, but also icons in the product: a handful of hand-inlined Heroicons v1 paths (20 × 20 `fill="currentColor"`) in `CourseCard` (x), `SemesterColumn` (refresh, trash) and `SearchableSelect` / `ErrorBoundary` (24 × 24 stroke) — they live inside those components' previews. Text glyphs do icon work too: `+` in "+N개 더 보기", `↔` in tooltips, `·` as a separator, `✓` before a satisfied credit count. Emoji are not part of the system; the source has two strays (🔴 before calendar holiday names, ⚠️ in a terms-page heading) that new work should not copy.
